## 📖 About the Project

**`IMSPhare`** is a modern, SaaS-style Portfolio Builder designed to help developers, designers, and freelancers showcase their work effortlessly. 

Unlike static templates, IMSPhare provides a **Dynamic Dashboard**, **GitHub Repository Sync**, and **Security-First Architecture**. Built with a focus on UI/UX using Glassmorphism and Dark Mode, it ensures your portfolio looks stunning on any device.

---

## ✨ Key Features

### 🎨 User Interface & Experience
- **Glassmorphism Design:** Modern, translucent UI components using Tailwind CSS.
- **Dark/Light Mode:** Persistent theme switching with system preference detection.
- **Responsive Layout:** Fully optimized for Mobile, Tablet, and Desktop.
- **Solar Icons:** High-quality, consistent iconography throughout the app.

### 🔐 Security & Trust
- **Enterprise-Grade Security:** Encrypted Personal Access Tokens (PAT).
- **Security & Cookie Policy:** Dedicated pages for legal compliance and user trust.
- **Auth System:** Secure Registration, Login, and Password Reset flows.

### 🚀 Core Functionality
- **GitHub Sync:** Automatically fetch and display public/private repositories.
- **Project Showcase:** Detailed views for projects with "ReadMe" rendering support.
- **Dynamic Dashboard:** Real-time stats, profile management, and account settings.
- **Email Notifications:** Custom Markdown-based Welcome and Reset Password emails.

## ⚙️ Installation

Follow these steps to set up the project locally :

### 1. Clone the repository

- git clone [`https://github.com/coodig/im-sphare.git`](https://github.com/coodig/im-sphare.git)

```sh
cd imsphare
```


### 2. Install Dependencies

```Bash
# Backend
composer install

# Frontend
npm install
```
### 3. Environment Setup
```Bash
cp .env.example .env
php artisan key:generate
Configure your database credentials in the .env file.
```

### 4. Database Migration
```Bash
php artisan migrate
```
### 5. Build Assets & Run
```Bash
# Build Tailwind Assets
npm run build 

# Start Server
php artisan serve
```
